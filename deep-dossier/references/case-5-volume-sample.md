# 五卷结构实盘样本（脱敏复盘）

> 取自一次真实项目（某地区一场持续数月的大规模政治风波及其百年结构背景），已按要求脱敏：只保留**结构与写法**，不含具体人名、数字与敏感细节。做下一个项目时，可整份当沿革模板抄。

## 一、项目形态

| 项 | 内容 |
| --- | --- |
| 题目 | 《（事件名）与"（性质定性）"未遂深度研究报告》 |
| 规模 | 5 卷＋2 附件，约 5 万字；原始检索材料 40 余件 |
| 生成方式 | 单一模型会话直写，单线程，逐卷落盘 |
| 交付状态 | 全案完成、机器自审通过（0 感叹号／无树状字符／无代码块围栏） |

## 二、八枝拷问的答案（可当模板）

| 枝 | 决定 |
| --- | --- |
| 1 时间跨度 | 长时段：从殖民地/前史时期（19世纪）一路写到当代；把本地历史上真实的反抗传统写成暗线；一次五年前的同类事件做对比专节；以新的国家安全立法后的局面收束 |
| 2 定性骨架 | 双线辩证：事件期主要矛盾＝外部策动的夺权未遂；根源矛盾＝依附遗留的阶级结构；三段式（纵火者/干柴/助燃剂）；各方责任分账，不洗地 |
| 3 基调与落点 | 冷峻解剖＋"可惜非可恶"收束；0 感叹号；结尾三问（谁推到这里／谁在纵火／谁没能拦住也没真心治好） |
| 4 核心问题意识 | 五问：为什么是这里为什么是此时／那只手怎么伸进来／谁在推方向盘／凭什么骗到青年又怎么用掉／谁失职谁获利然后呢；另加两节（跨案例对比、信息战解剖）作为专节嵌卷 |
| 5 结构 | 五卷：《病灶》《黑手》《暴动》《青年》《清算与出路》；附件：时间线大事记（180 年）＋数据看板与来源矩阵 |
| 6 来源分层 | 六层：一手官方（会议答问/统计/法案与法例原文/基金会数据）→官方媒体→本地私营媒体批判用→外部国家媒体作证据与靶子→立场相近评论→学术 |
| 7 敏感线 | 完整版＋四防火墙（口号转述不引原文／不做政治禁忌类比／在任高层不点名／争议事件走辟谣解剖），预留降敏版 |
| 8 执行细则 | 单模型会话直写；单线程分卷；先总纲后落盘；时间线随搜随建；篇幅由起草方定 |

## 三、五卷骨架与"脊梁句"的写法

| 卷 | 承载的问题 | 脊梁句写法示范 |
| --- | --- | --- |
| 一《病灶》 | 为什么是这里、为什么是此刻 | 用一句经济结构判断做脊梁（如"超级地租＝殖民地遗产的利息"）＋一句制度判断（如"主权回来了，意识形态机器还是别人的"） |
| 二《黑手》 | 那只手怎么伸进来 | 把资金账目、立法文本、庭审原文三层证据排成一条链，末尾用"五要素公式逐格打钩"收口 |
| 三《暴动》 | 谁在推方向盘 | 用"暴力指向谁"做性质试金石：攻击对象从权力机器滑向普通人＝性质暴露 |
| 四《青年》 | 凭什么骗到人、怎么把人用掉 | 用一句转译判断作脊梁（"分配焦虑被转译成身份怨恨"）＋领袖与普通参与者的去向对照表 |
| 五《清算与出路》 | 谁失职、谁获利、然后呢 | 三份责任各归各账，末尾用"止血不等于治愈"把落点抬起来 |

## 四、采集合成的经验值

- **约 10 波采集**：事件线→结构病灶→外部力量→组织与人群→清算→对比实证→历史与信息战→补料，每波 4-6 条，各自落盘编号，只回显标题
- **高价值来源类型**（下次优先搜这类）：会议书面答问（官方数字）、法律数据库原文、统计部门普查报告、主管部门年度数据、独立监察机构专题报告、国际住房/负担能力类年度报告、批判地理学与城市规划论文、左翼经济学者长文、境外基金会拨款调查、法院庭审记录
- **锚点数字的选法**：每个论点挑 1-2 个"能顶住查证"的数字当锚（官方来源优先），其余数字围绕锚点展开；口径打架的一律双列
- **原文上桌的位置**：庭审供词与通信原文、关键人物邮件原句、执法者现场原话、听证会证词、法案条款、量刑表——各挑一处，摆在最有力的段落

## 五、踩过的坑（下次直接避开）

1. **首卷偏薄**（不足 8 千字）：靠"补料批"加新事实（产业数据、制度分析）补齐，**不用抒情填空**
2. **超长命令行被拦**：多行循环＋中文变量易触发命令解析器限制——拆成单行、简单命令
3. **正则写法**：树状字符检查等要用字符类（写在方括号内），别转义成字面量
4. **专名形近字**：写完必扫（人名、地名、工具名）；建议在收尾自审里加一条"专名核对"
5. **素材边界**：手上若有更敏感的旧材料（他人分享的档案），**不主动读取、不引用、不搜索**——只写本项目的材料
6. **长篇报告容易拖成"事件流水账"**：每卷必须有自己的判断段落，否则就是资料堆积

## 六、交付动作清单（可复用）

1. 跑 `scripts/selfcheck.py "分卷/*.md" "附件_*.md" "00_*.md"` → 必须全 OK
2. 索引文件写"阅读顺序建议＋纪律清单＋版本记录"
3. 记忆或交接文档里记一行：报告名＋路径＋结构
4. 交付消息给：路径／结构表／字数／自审结果／验收要点／下一步提议（如是否抽降敏版）
