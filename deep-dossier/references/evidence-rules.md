# 证据规矩细则（原文引录 · 数据硬尺 · 来源分层）

## 一、原文引录清单（该贴就贴）

| 类别 | 贴什么 | 标注要求 |
| --- | --- | --- |
| 法律文件 | 条文原文、条约与附件、法案编号与签署日期 | 文号＋日期＋官方来源 |
| 司法材料 | 判词要点、庭审问答、量刑表 | 案件名＋日期＋报道来源 |
| 通信与邮件 | 通信原文（含错别字与口语） | 庭审展示记录／调查报道 |
| 当事人原话 | 证词、演讲、专栏、标语（口号类除外） | 说话人＋场合＋出处 |
| 历史文献 | 宣言、社论、报告、指令 | 原件名＋年月＋版本或收藏 |
| 官方答问 | 会议答问、发布会问答 | 会议＋日期＋提问人/答问人 |

**口号类例外**：涉极端政治主张的口号，正文一律**转述描述并标注性质**，不直接引用原文——报告不该成为传播载体。

**引文完整性**：引号内一字不动（含方言、口语、错字）；节略用"……"；**不得私自加感叹号**。

## 二、数据硬尺

1. **官方统计为骨**：优先会议答问、统计部门、法院文书、部门年报
2. **≥2 个独立源为肉**：关键数字至少两个来源（官方／媒体／研究机构各一）
3. **双口径并列**：规模类数字一律写"主办方称 X／官方称 Y"，不替任何一方背书
4. **宁少引，不引虚数**：口径打架又不确定的数字，写"约"或弃用
5. **全部进矩阵**：每条关键数据进附件二《数据看板与来源矩阵》，含数值、年份、来源
6. **量级感**：能算比例的就不堆绝对值（如"占被捕者约 39%"优于单写绝对数）

## 三、六层来源与使用规则

| 层 | 来源 | 用时怎么处理 |
| --- | --- | --- |
| 1 一手官方 | 会议记录与答问、统计部门、法院文书、法律与条约原文 | 直接引用，标文号日期；能查原件就引原件 |
| 2 官方媒体 | 官方通讯社与党媒 | 事实可用；关键数据交叉一源 |
| 3 立场鲜明的本地媒体 | 事件当事地的私营/独立媒体 | **批判使用**：只取事实拼图，立场标注清楚，绝不采其定性用语 |
| 4 外部国家媒体与机构 | 外部大国媒体、NGO 与智库简报 | **作证据与靶子**：引其报道证明外部如何站台造势；不作定性依据 |
| 5 立场相近的评论 | 与你立场同源的学者与评论者 | 分析框架优先采信 |
| 6 学术 | 期刊论文、学位论文、智库报告 | 结构与机制分析；标注作者与刊物 |

**交叉验证方式**：性质类结论用 1＋2；机制类结论用 1＋5＋6；外部角色类结论用 1＋4（让对方自证）。

## 四、采集与留档

```bash
# 分波入库（一次调用跑 4-6 条，各自落盘）
<搜索工具> --query "<理想页面的自然语言描述>" --num 5 --output text > 资料/NN_主题.md
# 只回显标题速览，正文留在文件里
grep -m3 '^Title:' 资料/NN_主题.md
# 写作时按需抽事实（不全文精读）
grep -ohE '.{0,80}(关键词).{0,120}' 资料/NN_*.md | head -20
```

**检索底账**（写进附件二末节）：件数、分组方式（事件线/官方数据/结构病灶/外部力量/组织与人群/清算/对比实证）、与卷的对应关系、可复核声明。

## 五、敏感四条（落地方式）

1. **口号**：转述＋性质标注（不引原文）
2. **类比**：不主动与本地政治禁忌事件做类比，也不擦边
3. **人物**：在任高层政治人物只引公开文件与官方表述，不做直接评点；下级官员、机构、资本代理人的责任批评照写
4. **争议事件**：统一走"证据链→官方澄清→谣言如何被量产与变现"的解剖路数，不单独做事实认定

**降敏版接口**：完整版写足为底稿；需要传阅时另抽一版，删去精确数字与最敏感段落——**先写足再删**。
