# deep-dossier · 深度案卷

> 一套写给 AI 用的**多卷深度调研报告标准作业法**：先拷问、再采集、后拍板、逐卷交付。
> 适合谁：需要产出五万字级研究报告的人——政治经济分析、行业深研、历史专题、事件全景复盘。

## 一、这是什么

把"写一份大报告"从灵感活变成流水线活：一份可复现的作业流程（拷问 → 采集 → 总纲拍板 → 逐卷落盘与验收 → 附件收尾 → 机器自审），配套六个模板、一份自查脚本、两篇方法细则和一个脱敏实盘样本。

**它管流程，不管内容**：写作立场与文风由使用者自己的标准决定；内置的立场框架是可替换参数。

## 二、里面是什么

```
deep-dossier/
├── SKILL.md                              给 AI 看的主文件：十二项配方＋八枝拷问树＋五阶段流水线＋机器自审
├── scripts/
│   └── selfcheck.py                      铁律自查：0 感叹号、禁树状字符、禁代码块围栏、头部字段、字数统计
├── templates/
│   ├── 00-total-outline.md               总纲模板（论点骨架＋待查项，供拍板）
│   ├── volume.md                         卷模板（元数据块＋论证链＋本卷小结＋衔接）
│   ├── volume-teaser.md                  逐卷交付用的两百字导读模板
│   ├── 00-index.md                       卷目录索引模板（阅读顺序＋纪律清单＋版本记录）
│   ├── attachment-timeline.md            附件一：时间线大事记模板
│   └── attachment-databoard.md           附件二：数据看板与来源矩阵模板
└── references/
    ├── stance-framework.md               立场框架细则（默认左翼唯物史观，可替换）
    ├── evidence-rules.md                 证据细则：原文引录清单、数据硬尺、来源分层
    └── case-5-volume-sample.md           五卷结构实盘样本（脱敏）：八枝答案、脊梁句写法、踩坑清单
```

## 三、怎么用

1. **最省事**：把 `SKILL.md` 全文复制，粘给任意 AI 当系统提示或任务前置说明（模板与细则按需一并贴上）。
2. **放进 skills 框架**：支持 Markdown 技能目录的框架（如 Hermes）直接把 `deep-dossier/` 文件夹放进技能目录——默认位置 `~/.hermes/skills/`，独立配置档则放在 `profiles/<名称>/skills/`。之后说"要一份多卷深度调研报告"即会被路由到它。
3. **其他框架**：把 `SKILL.md` 转成该框架的提示词或技能格式即可；`scripts/selfcheck.py` 是纯标准库 Python，任何环境都能跑。

**一句话用法**：告诉 AI 题目 → 它会先问八组问题（时间跨度、定性、基调、核心问题、结构、来源、敏感线、执行）→ 你拍板总纲 → 它逐卷写、逐卷交、每卷一验收 → 最后跑自查交全案。

## 四、速览表

| 维度 | 内容 |
| --- | --- |
| 立场 | 默认左翼唯物史观（三段式：外部操盘者/结构病灶/流行意识形态），**可替换** |
| 方法 | 八枝拷问 → 分波检索入库 → 总纲拍板门 → 一问一卷＋逐卷验收 → 附件双件 → 机器自审 |
| 底线 | 事实优先于立场；数据可溯源；引文不改字；0 感叹号；去私人化；不并发赶工 |
| 体量 | 每卷 0.8-1.5 万字，全案 5-6 万字级（重装，小题目不适用） |

## 五、使用须知（先读这句）

**这是工具，不是答案。**

- 它给的是一套流程和一个视角——怎么用、用得对不对，靠使用者自己的判断力；
- AI 的输出会出错（片面、过度自信、甚至编细节）——别把输出当结论；
- 立场鲜明 ≠ 自动正确：不同意的地方欢迎直接改（许可允许）。

**一句话：工具是工具，判断力得是自己的。**
